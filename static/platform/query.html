六源医疗数据服务

调用已登记的 SVC-MEDICAL-REMOTE-QUERY。每次执行从所选 GitHub / 南大云盘源文件重新读取，在本次请求内存中联邦计算；结果带来源路径、文件摘要和服务耗时。

HIS、EMR 需先在数据接入页连接南大云盘；LIS、PACS、IoT 与临床协同数据从公开 GitHub 分支读取。本服务只对该公开源使用合成数据。
