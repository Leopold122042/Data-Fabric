# 课题二现场操作手册

入口：http://127.0.0.1:8321/static/report/index.html?topic=2

预计 10—15 分钟。页面顶部“现场操作路线”显示八步完成状态，点击“进入操作”直达对应阶段。刷新页面会清空本页演示记录；完整证据展示结束前不要刷新。

## 现场顺序

| 步骤 | 点击与输入 | 应看到的结果 | 对应要求 |
|---|---|---|---|
| 1 | 点“重新开始本页演示”，进入接入阶段，点“登记本案例目录快照”；展开“数据对象” | 三源结构、各24条合成输入、主体/用途/期限和目录版本 | 多源元数据组织、创新点一 |
| 2 | 进入语义关联，点“运行多证据匹配”；检查下方身份与诊断映射表，展开“统一业务概念” | patient_id/patient_ref、visit_id/visit_ref对应；J18.9、J18.900、PNEU-03场景词典归一 | 语义建模与关联 |
| 3 | 进入逻辑集成，保留合同样例，点“生成策略对象草案”；依次点合规、跨用途、超期检查 | 放行、用途不符拦截、到期拦截；策略展示主体/用途/到期日/输出限制 | 创新点二 |
| 4 | 三种敏感等级分别选择后点“推荐执行路径”；最后再次点“检查合规用途访问” | 三种路径决策；最后恢复合规状态，否则不能继续执行 | 敏感等级驱动路径选择 |
| 5 | 进入编排阶段，选“正常完成”，点“确认需求并编排”；展开四步详情 | 四步状态和演示耗时；实际由合成输入计算的分组结果 | 编排与交付 |
| 6 | 先选择源未就绪场景运行，完成后选择失败重试场景运行 | 等待恢复、第三步第二次尝试；操作路线记录两种场景完成 | 等待/重试机制 |
| 7 | 进入反馈阶段，点“注入变更并完成局部处置” | 元变分→偏差→费用视图影响→除100归一→v2适配草案；计数保持一致 | 创新点四 |
| 8 | 点“查询全程证据链”，逐个展开右侧五类对象 | 登记、匹配、策略、放行、拦截、等待、重试、计量、变更记录 | 创新点三 |

修改合同会清除旧策略、放行结果及下游完成状态；重新生成策略、通过合规访问检查后再运行。正在运行时不要切换到合同编辑；如需从头演示，等待运行结束后点重置。

## 实际平台的对应操作

- 数据目录：打开 `/static/management/catalog.html`，点“扫描目录变更”，选择表或字段查看结构；点“影响范围”检查依赖，再到字段库查看定义。
- 语义工作台：打开 `/static/management/semantic.html`，选择业务概念，点“候选字段”，查看匹配分项、冲突和候选依据。只有实际确认保存的映射才能作为正式映射证据。
- 执行工作台：打开 `/static/execution/index.html`，查看实际保存的视图、方案、授权、任务与交付记录。页面示例条款不会自动成为这些后台对象。
- 合作约定：打开 `/static/execution/contracts.html` 查看实际约定记录。
- 偏差校准：打开 `/static/management/reconciliation.html` 查看实际偏差与处置记录。

## 要求核对与缺口

| 要求 | 当前可展示 | 尚未达到的部分 |
|---|---|---|
| 医院、医保、科研多源接入 | 本页三源合成结构；平台实际目录及本地来源扫描 | 本页并未连接真实医保、科研服务；不能作为真实三源连接验收 |
| 多证据匹配 | 本页约定词典与字段口径；实际语义工作台可查看候选证据 | 本页点击匹配不会运行通用语义模型或写回后台映射 |
| 合同策略与路径执行 | 本页合同规则解析、用途/期限校验；后台已有独立授权执行流程 | 本页未签发后台授权；真实沙箱/跨机构联邦设施未接通 |
| 编排与异常恢复 | 本页四步状态、等待/重试场景、实际合成数据聚合 | 本页计时与故障注入为模拟；实际任务需要在执行工作台单独运行 |
| 源变化与局部调整 | 本页预设单位变化、归一计算、影响对象和草案版本 | 通用自动偏差检测及自动修复不能由此示例证明 |
| 证据链 | 本页全过程事件可回看；后台有独立运行证据 | 本页事件存在内存中，刷新清空，不是持久审计记录 |

现场应将“操作演示覆盖了哪些环节”与“后台实际运行证据”分别说明。剩余缺口需要继续接入连接器、后台持久状态和设施执行链，不能以改动页面文字宣称完成。
