## 使用流程

1. A 先确认需求形成规格，或在 B 点击“新建医疗汇总方案”使用独立虚构样例。
2. 方案页可从规格中的服务集合自动生成节点，也可显式填写服务/视图节点、前置依赖和输入引用。保存只生成草案，不执行。方案与编译流程分别保存不可变版本；修改后重新确认。
3. 确认版本，以平台方“签发本地演示授权”，填写主体、用途对应的方案、期限、输出粒度和可选合作约定。切换身份不会获得另一主体的授权。
4. 执行进入持久化队列。任务页显示节点、失败、重试与时间线，可取消或重试。暂停会阻断后续节点与交付；恢复需要再次确认。
5. 交付页按当前授权读取结果、校验凭证、访问授权 API 引用或下载已确认下载模式的结果；可以清除平台副本，凭证仍保留。授权过期和撤销后禁止再次读取。
6. 医疗样例正常只返回“40—49岁、类别甲、5人”和小分组提示；另有明细拒绝、过期拒绝按钮，拒绝独立留痕，后端计算为零。样例为重建虚构数据，不是报告原始记录，不读医疗源库。

## 视图及节点示例

先从 A 数据目录复制真实字段ID，替换下面占位符：

```json
{"name":"地区计数","fields":["OBJ-region"],"group_by":["OBJ-region"],"joins":[],"filters":[],"output_mode":"aggregate"}
```

视图节点示例：

```json
[{"id":"query","operation":"view","view_id":"VIEW-实际编号","depends_on":[],"params":{},"retries":1}]
```

节点 `inputs` 是“参数名→上游节点ID”的映射，用于绑定已完成节点结果，并自动推导依赖。只允许注册服务、已定义视图、专用医疗虚构操作；不运行任意URL、命令或Python代码。

复杂概念表达式使用 `{ "field": "OBJ-ID" }`、`{ "literal": 2 }`、`{ "operator": "multiply", "args": [...] }`。允许 add/subtract/multiply/divide、eq/ne/gt/ge/lt/le、lower/upper/abs、coalesce、case，最大深度8。条件映射的 predicate 为此结构，then/else 为字段或常量；join 的 on 为字段ID对数组。除零返回空值，质量门禁可阻断。来源概念、映射或字段版本变化后拒绝旧视图。
