# 统一业务概念与外部字段映射

入口：概念映射。新增“建立客户、机构、指标概念”按钮，幂等建立三个业务对象和对应编号属性，使用稳定唯一编号、明确含义和业务域，不覆盖已有定义。对象概念用于组织属性，具体字段映射到属性概念。具体指标的值应补充统计口径、单位、范围和业务域后独立定义。

概念可维护同义名称、上下文关键词、数据类型及数值/文本长度范围。来源表必须先纳入平台目录，才会获得平台字段编号并参加匹配。

## 候选匹配

1. 排除已删除字段、明确类型冲突及完全不重叠的取值/长度范围。
2. 按字段名/同义名称35%、结构类型20%、取值摘要25%、业务说明/业务域/表名及相邻字段上下文20%排序。
3. 缺少证据不当作匹配成功。匹配分为启发式分数，不是统计概率。分数至少0.8、证据覆盖至少0.8、同表领先至少0.1且无不确定项才标为建议；其余交人工判断。
4. 每个候选展示分项、排除原因和缺失证据。建议只能生成草稿，确认必须填写复核依据，不自动生效。

外部“立即检测”及定期检测提取字段行数、非空数、数值比例、数值最小/最大值及文本长度摘要；不保存原始值。先纳入目录再检测即可同步字段剖析。剖析变化使已确认映射转为待复核。

外部连接器将许多列保留为VARCHAR，不能仅因内容看似数字就宣称它是可直接计算的数值字段。物理类型冲突仍会被排除；须先确认源类型或受支持的转换方案。

## 四类映射

- 直接对应：一个字段。
- 有条件对应：结构化predicate、then、else；条件字段可与输出字段不同类型。
- 多字段计算：声明operator和args，支持加减乘除、绝对值、大小写及coalesce等已有运算；校验输入及输出类型。
- 跨表关联：声明on字段对和field输出字段；校验跨表、字段声明及关联键类型。

页面有“四类映射说明”与表达式示例。复杂映射使用受限结构化表达式，不接受任意代码。映射定义固定概念及源字段版本，变化后需复核。取值排序的范围检查只排除完全不重叠的明确冲突，不将部分越界等同于确认。

已确认映射供平台服务定义及支持的查询执行器使用。本次没有将概念映射自动改写为任意云盘SQL，也不绕过外部资源授权。云盘数据读取仍执行当前资源授权。
