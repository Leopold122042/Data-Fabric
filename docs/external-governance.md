## 使用流程

1. 连接云盘，扫描目录得到来源表。选择需要共享结构的表纳入平台资源目录。
2. 在“外部数据检测与访问授权”多选来源表，点击“立即检测所选表”建立基线。
3. 设置检测间隔（最低60秒，默认300秒），启用定期检测。按表解析实际源内容并对比字段、类型、行数和内容摘要；不存储数据行或凭证。
4. 点击“授权所选来源表”，填写主体、用途和有效期。当前沿用本地演示主体，不是跨机构真实身份系统。
5. 查询时选择当前身份的访问授权。查询前和结果返回前检查主体、用途、云盘账户、表范围、期限、撤销状态及结构摘要。统一虚拟表的所有所选来源都必须在授权范围内。
6. 可撤销授权；检测到结构变化会使相关授权失效。内容变化不自动撤销授权，但留存变化记录。已纳管结构同步到平台目录并使用已有映射失效和影响分析逻辑。

## 范围和限制

- 适用于扫描登记的云盘来源表和由它们生成的统一虚拟表。
- 检测内容变化、字段/类型/行数变化、不可用及恢复。不存储逐单元格前后值；错误不自动推断为文件删除。
- 新文件、新工作表、移动或改名后的路径仍需重新扫描发现。
- 定期检测使用当前服务器内存中的有效云盘会话。不会延长会话寿命；断开、到期或服务重启后需重新连接并启用检测。
- 授权是表级读取授权。不是字段级脱敏、跨机构身份认证或第三方存证。
- 旧的任意会话SQL与预配置虚拟查询入口没有稳定资源授权绑定，在完整平台中拒绝读取。应使用扫描后的资源查询入口；连接器独立测试应用不注入完整平台策略。
- 后台定期检测是平台方配置的源维护能力。需求方读取仍需独立授权；没有把云盘令牌复制给后台业务方案。

实现文件：`execution/external/governance.py`、`execution/external/routes.py`、`external_api.py`、`platform_core/bootstrap.py`、`static/platform/governance.js`。持久化元数据、变更、授权和决定复用 execution 控制库；凭证只在内存会话。
