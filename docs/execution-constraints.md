# 需求执行条件与交付检查

需求确认后，范围、时间、质量和交付规则会随规格版本进入方案。授权绑定整份方案及执行条件摘要，提交、节点执行前后、交付和读取结果时重新核对。旧规格、旧方案或旧授权缺少这些绑定时，需要补充规则、重新确认并授权。

## 页面操作

1. 在“需求受理”创建或编辑需求，填写对象范围说明、时间窗、用途、质量、交付时限与交付形态。
2. 点击“设置执行条件”，选择实际范围字段、比较方式、取值、数据时间字段和允许的交付方式。选择全部对象也需要明确勾选。当前表单支持一项范围筛选，接口支持最多20项同时成立的筛选；表单不会覆盖已有多项筛选。
3. 受理岗核对范围说明与实际筛选一致，并单独确认执行条件。未配置或未确认时，不生成可执行规格。
4. 从规格生成方案，输出粒度和交付方式由规格预填；只能提高完整率，不能放宽规则。逻辑视图必须包含范围及时间字段。
5. 在目录中确认输出字段的分类。未确认、健康信息、个人标识、敏感字段不能直接交付；换名或经概念映射后仍保留源字段分类。普通分组不会使敏感字段变成非敏感字段。
6. 确认方案并签发本地授权，再提交执行。授权不能扩大行数、降低分组阈值、改变用途/粒度或超过截止时间。

日期按UTC日界计算，起始日期包含当天，结束日期包含当天；带时区时间的区间为左闭右开。查询使用SQLite `julianday`比较实际时间，兼容ISO日期及带时区时间。无法解析的源时间值不进入结果。当前交付时限同时是执行及结果读取截止，超过截止时间停止访问。

## 支持的执行路径

- **数据行查询**：使用本地SQLite逻辑视图。范围条件及时间谓词追加到源端SQL，和视图已有条件同时生效；不能用节点参数或上游输入覆盖。缓存键包含实际执行条件，不同人群/时间窗不共用结果。
- **当前元数据快照**：仅使用`SVC-META-CATALOG`及以其为handler的已发布服务。时间窗限制执行时间，输出仅包含源标识、源名称、表数量，不输出业务记录、业务行数或原始对象。该路径不能替代患者范围查询。
- **医疗虚构样例**：固定12人数据和已审核的年龄段/类别/人数输出，不接受绑定其他规格来绕过范围规则。

不能落实数据范围的旧handler会在创建方案时拒绝。质量目前支持完整率；成本预算、其他质量指标等未提供执行适配器的条件会明确拒绝，不能只保留文字后继续执行。

## 接口示例

需求的`execution_constraints`保存可执行规则；自然语言`object_scope`保留给人工审阅。字段ID来自版本化目录，不能用任意SQL表达式替代。

```json
{
  "object_scope": "A组对象",
  "time_start": "2026-01-01",
  "time_end": "2026-01-31",
  "purpose": "research",
  "quality": "完整",
  "deadline": "2026-12-31T23:59:59+08:00",
  "delivery": "汇总",
  "execution_constraints": {
    "scope": {
      "kind": "rows",
      "filters": [{"field": "目录中的人群字段ID", "op": "=", "value": "A"}]
    },
    "time_field": "目录中的时间字段ID",
    "output_mode": "aggregate",
    "circulation_modes": ["controlled_compute"],
    "quality_min_complete": 1,
    "max_rows": 100,
    "min_group_size": 5
  }
}
```

确认时需要`confirmations.execution_constraints=true`，同时保留内容、附件和缺口确认。没有显式筛选但确实允许全部对象时，使用`scope={"kind":"rows","filters":[],"all_rows":true}`；时间字段仍必填。元数据快照使用`scope={"kind":"metadata"}`、对象级交付且不绑定数据时间字段。

## 输出保护

输出列与类型由固定医疗/目录适配器或目录字段血缘生成，客户端和查询结果不能自行声明安全。缺列、额外列、嵌套对象、未审核的附加结果属性，以及检测到的联系方式/标识/敏感内容都会拒绝。完整率使用实际结果计算，外部`quality=true`不能跳过检查。

输出规则和执行规则摘要写入本地签名凭证。读取结果重新检查授权、截止时间、方案版本、完整输出结构、字段分类、完整率、分组阈值和行数，同时校验凭证签名及结果摘要。旧结果不能绕过新检查。

内容模式检测是字段分类与白名单之外的辅助检查，不能识别全部自然语言隐私内容。目录分类需由受信任管理方维护。通用查询的`min_group_size`计量关联结果记录数，只有固定医疗样例的计数对应独立人数；通用实体去重与更复杂的隐私计算仍需单独实现。

## 连接错误修复

- 管理动作`pause_review`映射为执行命令`pause`，已排队任务及计算完成后的交付均受暂停控制。处置前核验工单版本和目标方案版本，重复的旧页面请求不能先暂停再报版本错误；执行状态与控制回执在同一事务提交。
- SQLite剖析统一`count/non_null/null_rate`，兼容旧计数字段；无有效值或异常计数不被当作取值证据。
- 有效人工确认的直接映射参与后续候选排序，并展示规则来源。旧版本、失效或停用映射不参与；类型/范围硬否决和人工确认保留。
- 外部已保存目录、集合及其管理目录桥接均显式以UTF-8读取，消除Windows默认GBK造成的中文读取错误。
