# 自动发现与永久虚拟表（无需确认）

在“逻辑表目录”填写云盘目录并开始扫描。系统遍历支持的文件与压缩包，自动生成来源映射和统一虚拟表。扫描完成后仅显示目录→文件/压缩包→工作表名称树，不自动执行数据查询。点击表名旁的“到查询区”设置来源范围，在查询区选择返回字段与筛选条件，主动点击“按字段查询”后才读取并展示最多 200 行。未连接时只弹出数据源登录窗口，不要求确认表结构。

## 自动映射规则

- 明确的指标标题和排名/对象/分值区块自动转换为统一指标记录，保留来源和原表口径。
- 无法可靠识别的复杂表头保留原始字段、未命名列与说明行，标注业务含义未识别，仍可查询。不自动推断主外键或跨表业务关联。
- 可选“保存表头调整”允许修正 Excel 表头行；没有强制预览或确认步骤。源字段未改变时保留用户自定义表头，变化后重新自动识别。
- 查询时重新检查源结构并自动更新定义。旧字段删除后，引用旧字段的查询可能需要更新条件；不要求人工确认。

永久定义存放在 `private_catalog/discovered/`，统一表成员保存在其 `collections/` 子目录。按账户隔离，原始值与令牌不写入定义。匿名可看概要，实际数据查询需要连接所属账户。迁移时一起备份这些目录与 `private_catalog/cesai.json`。

统一表带来源目录、文件、包内文件、工作表、来源表编号和解析后行序号；业务字段使用 `数据·` 前缀。同名字段纵向对齐，缺失字段为 NULL。同名不代表同义，各版本来源均保留，不自动去重。DuckDB 用 UNION ALL BY NAME 联合临时来源表，避免为每条记录物化大量空列。

## 范围与限制

每次扫描最多 100 个文件/包内条目、20 个目录、3 层子目录；队列最多 1000 项。单文件限制沿用读取模块。扫描失败或跳过的项目列出原因，统一表只覆盖本次成功解析的来源，并标记扫描不完整。暂停仅在当前会话内可继续，重启后需要重新扫描。

重新扫描同一账户/目录更新稳定编号的统一表成员。源端移除的历史单表定义暂不自动删除。查询会下载所选来源文件，同次查询共享文件下载；业务字段筛选在解析后执行，并非远端只传输匹配行。联合读取最多 200 万个有效单元格，显示最多 200 行，SQL 执行超时 5 秒。损坏、格式不支持或超限仍会报错，取消确认流程不取消读取限制。

## 验证

`python -m unittest test_external_discovery` 覆盖自动识别、未知结构回退、旧待确认定义升级、结构变化自动更新、可选表头调整、稳定 ID、账户隔离、联合读取、来源选择和持久化。建表不需要人工确认；查询只由用户主动触发。另以当前 54 张已读取来源的本地快照验证全表联合计数，不额外修改真实云盘。

## 移除与恢复来源表

目录树每个表名旁有“移除此表”。操作仅修改当前账户、当前统一表的成员关系，不删除云盘文件或底层来源定义，其他统一表不受影响。排除名单永久保存在统一表定义的 excluded_source_ids，后续扫描不会自动重新加入。可在“已移除的表”中恢复，也允许移除全部成员。写入设置需要登录所属账户；移除后清空旧查询面板，过期查询中显式引用被移除来源会被服务端拒绝。

## 新旧查询范围

“虚拟表查询”统一入口默认选择扫描生成的新虚拟表。下拉框可显式切换到旧 CESAI 指标表（原 3 个文件、15 个工作表），两种映射分别查询，不自动合并结果。新表只使用其当前保留的来源；移除设置不改变独立的旧表。切换查询范围只显示字段和条件，不执行查询。结果提示包含虚拟表名称，旧表的来源数表示文件数，新表的来源数表示来源工作表数。

## 关键词搜索

新虚拟表查询区只提供关键词搜索，不再显示返回字段勾选或按字段筛选器。输入“北京”在所选来源全部业务字段中进行文字包含匹配（英文忽略大小写）；返回本次有命中行的来源表的字段，并带来源信息；未命中表的字段不进入结果。业务字段仅在本次全部匹配行中至少有一个非空值时显示；NULL、空字符串和纯空白视为空，数字 0 保留。判定在 200 行展示限制前完成；不修改永久表定义。匹配先于 200 行展示限制，所有命中表的字段按名称取并集，缺失值以空白单元格显示。空关键词浏览数据；最多返回 200 行，超出时明确提示。搜索采用文字包含匹配，不把关键词拼入 SQL；百分号、下划线和引号均按字面文字处理。来源选择和表移除仍有效，切换范围不自动查询。旧 CESAI 可选入口同样提供包含搜索。

## 浏览扫描目录

扫描路径旁的“浏览云盘目录”从云盘根目录列出子文件夹。支持逐层进入、面包屑导航、返回上级和刷新，并显示当前文件夹数量与文件数量。“选为扫描目录”只填入扫描路径，仍需主动点击扫描按钮。没有子目录时可选择当前目录扫描文件。未登录或会话过期时先连接再继续浏览，更换账户、断开或释放会话时清空旧目录展示。浏览通过现有 box/list 接口只读取目录元数据，不下载文件内容。

## 搜索结果按来源表分组

页面按来源表编号、文件、包内文件、工作表分组呈现返回结果，不再显示跨表字段并集宽表。每组仅显示该组当前返回行中至少有一个非空值的业务字段；保留数字 0，移除纯空白列。组标题显示文件名、工作表名及当前展示条数，完整来源路径折叠在“来源位置”中。来源元数据不再逐行重复，与来源信息完全相同的规范化业务副本列也不重复显示。搜索范围、源数据、永久映射和接口返回值不变，仍受全局 200 行展示上限限制。
