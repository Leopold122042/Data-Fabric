# 云盘虚拟逻辑表

外部数据接入页面自动显示已保存的虚拟表目录，查看表定义不要求登录云盘，不向云盘发请求，也不占用新的数据会话。未连接时展示表名、字段、工作表、映射和关系说明，隐藏具体文件路径。

首次查询时自动弹出云盘连接框，填写 WebDAV 用户名和令牌并点击“连接并继续”，成功后继续原查询。取消或按 Esc 返回目录，不清除查询条件。GitHub 与云盘文件接入入口收起在页面底部“接入其他文件”面板中。验证成功后仅在当前浏览器会话的服务器内存中保存凭据，清空页面令牌输入框；刷新网页后同一有效会话可继续查询、浏览目录和打开来源文件，无需重新输入。不会写磁盘、浏览器存储或响应。会话空闲 30 分钟后过期，重启服务或释放会话会清空授权。

点击“断开连接”立即清除会话凭据、虚拟文件缓存和普通云盘逻辑表，虚拟表定义保留。更换账户需要重新输入用户名和令牌；切换失败不继续使用旧账户。当前未实现平台用户登录与目录 ACL，公开目录仅为概要；未来多人部署应使用入口认证或增加平台权限管理。

本机已配置 `cesai_indicator_index`（CESAI 地区与部委指标索引），映射三个实际源工作簿的 15 张排名工作表。建档时识别到 2646 条指标记录。不是全云盘扫描，也没有把未检查的原始打分表、年度目录或其他资料库自动关联。

## 持久化与执行

`private_catalog/cesai.json` 保存源文件路径、压缩包内部路径、工作表选择、关系说明和统计验证信息，已加入 Git 忽略，文件权限 0600，不保存评分明细或令牌。部署到其他电脑需单独迁移该目录；目录不是共享用户认证系统。

查询先解析 SQL；对单表查询中明确的“指标 / 口径”等值或 IN 条件，根据 sheet_capabilities 选择源文件与工作表。OR、子查询、CTE、联表、计算表达式或缺少能力映射的场景，保守读取可能相关的全部来源，不使用字符串匹配猜测条件。能力声明也是虚拟视图的映射范围；源端新增指标需要更新目录后才纳入虚拟视图。

只下载选中的来源，并只解析选定工作表的单元格。Excel 仍需下载整个选中的工作簿；RAR 仍需获取整个压缩包，不能做到云盘服务端逐行筛选。数据在临时 DuckDB 中计算，SQL 结果每次重新计算且请求结束释放。

原始文件字节在当前浏览器会话的内存中缓存最多 5 分钟、总计最多 60 MB，不写磁盘，不跨会话共享；缓存以用户名和令牌的摘要隔离，凭据改变时不复用旧数据。每次使用缓存前通过 HEAD 检查 ETag 或 Last-Modified 与 Content-Length；版本变化、过期或勾选“本次强制刷新源文件”时重新下载。源端未提供可用版本信息时按 5 分钟 TTL 复用，不能保证这段时间内立即反映修改。版本检查出现认证或网络失败时不返回旧缓存。

页面提供“指标”和“口径”筛选，并显示本次选中的来源数量、工作表、缓存命中情况和文件下载时间。重启平台、会话清理或释放当前会话都会清空缓存。

当前字段：资料集、口径、对象名称、指标、排名、数值、来源文件、包内文件、工作表、记录位置。记录位置是解析后非空记录序号与列区间，不是原始 Excel 行号。数值使用文件内缓存值，不执行宏或重算公式；空值、非数值和平均值汇总行不作为对象评分。

## 关系与口径

同一资料集与口径下，按对象名称精确检索相关指标，不按排名关联，不自动处理名称别名。地级/地级市/地市的排名工作表归到“地市”；“省份（原表口径，待确认）”与“省+市汇总”分开保留。相同指标出现在多个来源时保留来源，不默认同义，不相加；实际业务口径与测评年份仍需参考原报告确认。

```sql
SELECT * FROM cesai_indicator_index
WHERE "对象名称" = '北京市'
ORDER BY "口径", "指标";

SELECT "对象名称", "指标", "数值", "来源文件", "工作表"
FROM cesai_indicator_index
WHERE "口径" = '部委' AND "对象名称" = '教育部';

SELECT "口径", "指标", COUNT(*) AS "记录数"
FROM cesai_indicator_index GROUP BY "口径", "指标";
```

结果最多 200 行，SQL 计算超时 5 秒，映射数据最多 50000 行。源端读取和解码有各自的大小与超时限制。某个必需来源或工作表失败时整个查询报错，不将不完整结果伪装为完整结果，也不返回旧缓存。

“打开来源文件”复用原有文件入口；压缩包会展示内部文件供选择。此操作会按原有规则替换普通外部表，但不会覆盖持久化虚拟表目录。

## 测试

运行 `.venv-external/bin/python -m unittest test_external_virtual -v`，覆盖排名区块转换、按对象匹配、每次查询重新读取、缺失工作表失败及目录访问验证。测试默认模拟云盘读取，不依赖本地私有目录或真实凭据。

新增测试：`test_virtual_planning.py` 覆盖来源/工作表筛选、复杂 SQL 回退、缓存命中、版本变化、TTL、强制刷新、凭据与会话隔离。
