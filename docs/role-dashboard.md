# 按身份组织的首页与共用动效

## 目标与分区

首页在统一导航框架中回答当前身份最常见的办公问题。设计以 1280×720 桌面内容视口为基准：核心指标、重点摘要和目录入口集中在首屏；窄屏和放大字体自然纵向展开，不裁切主要内容，不用卡片内滚动条换取单屏。

| 身份 | 主要问题 | 主要内容区设计权重 |
| --- | --- | --- |
| 平台方 | 数据规模与分布、发生了什么变化、哪些事项需关注 | 资源 50%；事件与运行 30%；业务待办 20% |
| 供给方 | 本方服务被谁用于什么需求、调用状态、定向评价 | 资源服务 35%；使用情况 40%；反馈协作 25% |
| 需求方 | 本人的申请阶段、交付凭证、异常与下一步 | 需求进度 40%；交付异常 35%；服务与待办 25% |
| 审计方 | 元数据变化、访问核验、运行证据、风险 | 事件变更 40%；授权证据 35%；风险复核 25% |

权重指导信息层级，不承诺每个卡片的精确面积百分比。入口仍遵守三类权限，不在按钮或目录名称后添加“只读”。侧栏默认展开当前页面所在分组，其他分组折叠。

## 数据口径与边界

- `/api/dashboard` 用请求身份构建服务端投影，禁止把全平台数据传到浏览器再隐藏。工单复用 `WorkOrders.projections`，保留固定版本关联、供给方历史参与边界和定向评价规则。
- 患者、人次/记录、文书与体征点分别显示单位。目录对象数量包含未删除的表与字段，按来源分布；它不等于记录行数。
- 供给方“关联目录对象”只统计本方服务 `source_objects` 明确引用的有效对象，不能解释为资源所有权。未登记关联不会猜测归属。
- 供给方使用情况区分申请使用、编入方案和实际调用。反馈来自按身份投影的工单，不展示跨供给方方案的私有整体评价。
- 事件为当前留存窗口，最多 800 条，不解释成今日累计。核验、授权和交付按存储记录计数；“登记授权”包含已过期、已撤销记录。
- 交付卡片仅提供凭证入口，不返回结果数据、查询约束或签名内容，也不预先宣称“可领取”。结果访问由原执行域重新核验。
- 来源状态表示最近一次扫描结果，不代表持续在线。来源、事件、风险局部读取失败时显示不可用，未取得的指标显示 `—`，不替换成零。
- 本版显式刷新；不自动轮询全量工单、补造历史曲线或使用预览图固定数字。原先合成的 24 小时趋势不再出现在首页。

## 明细归属

| 内容 | 入口 |
| --- | --- |
| 来源、目录对象、云盘资源 | 资源目录、外部数据接入 |
| 科室、诊断、来源规模 | 查询中心 → 医疗数据统计；当前仅平台方可访问 |
| 服务使用与需求全过程 | 协作工单 |
| 元数据全量窗口 | 元数据事件 |
| 任务、授权、证据、凭证 | 执行与交付及安全与治理对应目录 |
| 规则执行与本地风险 | 自动化规则、风险监测 |

首页仅保留最近 3 条工单、4 条服务使用、2 条反馈等摘要，明确提供完整目录入口。短弹窗展示事件或来源摘要、统计口径与链接，不嵌套完整页面。

“平台说明”中的“角色首页与信息分区”独立章节与首页共用 `static/shared/dashboard-guide.js`，描述角色范围、分区、数据口径和交互原则。

## 图表与视觉组件

2026-11-02 完成四类首页的视觉重构。布局参考 Ant Design 的“先总览、再明细”信息层级与 Steps 节点表达，图表提示遵循 Carbon 的悬停及键盘聚焦原则，组件以本地 SVG、CSS 和原生按钮实现，不引入外部图表资源。

| 组件 | 规则 |
| --- | --- |
| 图标索引 | 统一 24×24 线性图标，覆盖侧栏分组、指标、事件、服务、凭证、风险及操作；装饰图标不重复进入辅助技术朗读 |
| 来源分布 | 数量、占比和来源标签同时展示；HIS 蓝、LIS 绿、PACS 紫、EMR 琥珀、IoT 青，其他来源灰蓝；排序改变不改变来源配色 |
| 图表交互 | 条形图采用整行命中区域，悬停和键盘聚焦显示完整标签与统计口径；Escape 可收起提示，点击显示短摘要及目录入口 |
| 审计核验 | 环图展示已保存核验记录的通过率，条形图列出拒绝原因；无记录时显示 `—`，不暗示全部通过 |
| 需求进展 | 圆形节点和连接线呈现五阶段；勾选表示完成，蓝色节点表示当前，警示图标表示异常；保留下一步说明 |
| 服务使用关系 | 将需求与使用主体、关联服务、使用状态分列，区分申请、编入方案和实际调用 |
| 操作入口 | “详情”“查看全部”等统一为带图标的小按钮，明确边框、悬停、按下、焦点四种表现 |
| 屏幕适配 | 同时按宽度和可用高度选择布局；宽屏高度不足 1000px 时使用紧凑样式。图表行与记录保留内容最小高度，空间不足时页面纵向展开，卡片内容不越界 |

参考：[Ant Design 数据可视化页面](https://ant.design/docs/spec/visualization-page/)、[Steps](https://ant.design/components/steps/)、[Carbon Tooltip](https://carbondesignsystem.com/components/tooltip/usage/)。

## 共用交互动效

共享壳加载 `motion.css` 和 `motion.js`，覆盖使用同一壳的总览、管理、执行与平台页面。

- 按钮/链接反馈：120ms 颜色、边框、阴影；按下位移 1px，不延迟执行。
- 内容进入与页内选择：180ms 淡入及 3–4px 位移；仅用户触发的切换动画，不让后台更新反复闪动。
- 目录及 `details` 展开：200ms 高度过渡，支持连续反向点击和键盘激活；结束后恢复自然高度。
- 原生 `dialog`：180ms 淡入淡出及微小位移；继续使用浏览器焦点约束、Escape 和返回焦点机制，不人为延迟业务提交。
- 尊重 `prefers-reduced-motion`；运行中开启此设置会结束展开动画。禁用按钮不播放按压效果。

动效只作用于展现，不改变权限、表单校验、请求顺序或接口结果。尚未接入真实跨机构身份认证；本次没有扩大已有业务修改权限。

## 本轮验证

- 后端：`test_dashboard`、`test_work_orders`、`test_access_policy` 共 38 项通过；覆盖角色隔离、结果内容不出现在摘要、较早异常的优先展示、局部失败及原工单版本边界。
- 前端：`test_dashboard_model.js`、`test_motion.js`、权限及工单界面模型共 31 项通过；新增通过率分母与无记录处理、异常节点与未知状态回退用例。动效用例覆盖连续反向点击、运行中切换减少动态效果与原生展开的辅助技术状态。
- 浏览器：补充复现并修复 1600×850 下的柱条重叠与反馈记录越界。四身份在 1500×850、1600×850、1920×900、1920×1080 下保持一屏；1280×720、1100×700 高度不足的页面允许向下延伸，各卡片及柱条均无内容溢出。390px 窄屏自然展开且无横向溢出。已检查环图图例间距、下一步说明、键盘提示及 Escape 收起、摘要弹窗焦点返回、工单跳转及平台说明章节。
- 手工刷新使用实际数据；空记录不补造数据，失败时保留上次快照并显示错误。
