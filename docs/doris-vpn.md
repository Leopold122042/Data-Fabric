# 通过 VPN 接入 Doris 实时数据

## 配置一条连接

让数据源负责人提供 Doris 查询端点、专用只读账号、允许的业务表或视图和字段字典。建议先从一张批准的视图开始。账号在源端只对这些对象具有 SELECT 权限，平台也只扫描配置的对象。

本机已连接 VPN 时，在项目目录执行下面的命令。示例以 Doris 端口 9030 为例，用户名和表名以实际授权为准。

```bash
.venv/bin/python configure_doris.py nju --name "南大医疗 Doris" \
  --host 192.168.0.183 --user medfabric_reader \
  --table bdm.已授权视图名 --vpn-interface 'utun*'
```

请将示例视图名换成 Doris 中真实的英文表名。增加 `--table` 可登记更多表。需要发布记录数服务时，添加 `--count-service DB.TABLE`，并同时允许该表。这个参数只发布固定的实时记录数服务，少于 5 条时隐藏结果。

命令交互读取密码，校验元数据后原子写入 `~/.config/medfabric/doris.json`。可通过 `MEDFABRIC_DORIS_CONFIG` 指定文件。文件需为 600 权限，或由 Windows 使用等效的私有 ACL。每个连接用不同的 ID，重新运行一个 ID 会更新对应连接。不要将该文件复制进仓库或发布包。

默认启用并校验 Doris TLS，内网 CA 通过 `--ca-file` 指定。仅当数据方确认数据库链路由受管 VPN 保护、Doris 未启用 TLS 时，使用 `--vpn-interface`。macOS 支持指定具体接口或 `utun*`，Linux 使用明确的接口名。配置必须使用 VPN 内网 IP。平台在每次登录数据库前检查该目的地址的路由是否经过所配置接口。远端网关场景优先提供能校验证书的私有 TLS 端点。

## 接入平台查询

1. 重启平台后使用 4 级账户打开「数据服务」，确认 Doris 源显示最近扫描成功。扫描只同步表和字段结构，VPN 恢复后会自动重试。
2. 在数据目录和字段库核对业务含义、类型和分类。入库名称按 `doris_连接ID__库名__表名` 生成，同名表在不同源可分别引用。数据源的字段备注会作为待审核定义的依据。自然语言和专业查询使用已确认字段。字符串时间先确认存储格式。原生 DATETIME 有数据时间窗需求时，登记 `--time-zone`。
3. 在「自然语言查询」选择已确认的字段，或在「专业查询」按目录表名编写平台支持的有条件 SELECT。确认意图后，平台按当前授权到 Doris 读取。涉及 Doris 的新执行不复用旧结果。查看多源结果需要在目录确认正确的等值关联，在逻辑视图中显式选择。当前专业和自然语言入口仅支持已确认的 patient_id 关系；原库 pid 或 visitid 不会自动等同于平台患者 ID。
4. 已发布的记录数服务可在「数据服务」点击实时查询，或用已认证的 4 级平台会话请求 `POST /api/portal/services/{service_id}/run-live`。调用记录带来源和证据编号。

## 多 VPN 与远端常驻

平台后端负责访问数据库。浏览器和 DBeaver 可以关闭，运行后端的主机必须持续拥有到每个源的路由。多个源独立扫描和连接，查询工作台目前有两个执行 worker，额外请求进入原有队列。单次联合查询按已确认关联装载数据，可能依赖前一张表的结果来缩小后一张表的查询范围。

- **不重叠的内网网段**可由管理员在服务器上运行多条受管分流 VPN，只把各自数据库网段交给对应隧道。
- **内网网段重复、VPN 客户端互斥或需要交互验证**时，应由数据方或运维为每条 VPN 配置独立常驻接入主机或独立网络命名空间。向平台提供不同的私有 TLS 端点，保持每个网关只访问获准的 Doris 服务。平台配置每个端点，业务查询可以并发。
- **本机 VPN**可用于首次接入和验证。Mac 离线、休眠或 VPN 登录过期时，该路径不可用。远端长期运行需要受管服务凭据或数据方提供的内网网关，平台轮询和重试无法代替 VPN 侧授权或 MFA。

如后续数据库采用 PostgreSQL、SQL Server 等其他协议，可沿用各源独立 VPN 的网络拓扑，再补对应只读数据库驱动和执行适配器。

## 远端定时检查

远端由 `medfabric-vpn-check.timer` 每分钟启动一次检查。配置了数据库连接时，检查对应 VPN 路由、TCP 端口及只读账号能否执行 `SELECT 1`。没有连接配置时，只探测初始目标和实际路由。检查不会自动提交 VPN 登录，也不把数据库可达误判为 VPN 已认证。

- 查看当前结果可读 `/mnt/medfabric/runtime/vpn-check.json`。
- 查看下次运行可执行 `systemctl list-timers medfabric-vpn-check.timer`。
- 查看状态变化可执行 `journalctl -u medfabric-vpn-check.service -n 30 --no-pager`。
- 当平台使用自定义 Doris 配置路径时，在巡检专用环境文件 `~/.config/medfabric/doris-check.env` 设置相同的 `MEDFABRIC_DORIS_CONFIG`。密码仍由原私有配置保存。
